## Why instance-only repairs were insufficient

1. **Permission provenance crossed a transport seam.** A terminal's observe role and a device's right to read file-derived plan content are distinct. A local-only readOnly test misses a machine relay which authenticates with a full machine token. R2 carries an immutable, reduction-only prompt-screen policy from WS upgrade through every relay before any snapshot/read, independent of terminal mode. Full and observe-owner controls must retain permitted content; watch/reduced-owner controls must exclude both private body and path.
2. **An oracle needs an authenticated executable setup.** Typing the expected response fixed R1's compile error but did not establish that each new policy case can complete its actual HTTP/WS handshake. R3 must trace credentials, authenticated snapshot, attachment/interest and policy assertions across all eight cases, without disabling token protection to obtain a green test.
3. **Visible behavior is not DOM implementation.** A collapsed `<details>` may keep descendants and layout boxes. The user invariant is a compact, visible summary with hidden details and reduced panel height, not removed nodes or zero descendant rectangles. Every claimed PASS still requires a fresh real click/observation on the corrected harness.
4. **Fault injection must prove the fault.** An offline toggle is not evidence a live WebSocket closed. Reconnect acceptance must observe a real close and new handshake/snapshot, then the authoritative REST reconciliation and correct view. If that proven transition omits REST, it is a product finding, not permission to change the criterion.
5. **Input delivery needs an actual native observer.** HTTP 200 and `prompt_matched=true` do not alone prove PTY bytes landed. A test-owned raw-mode input recorder must observe the selected key and the updated native screen/REST state. No user pane receives fixture keystrokes.
6. **Error classification must be precise and transparent.** A standalone `createServer` intentionally answers 404 for optional telemetry when none is supplied. Expected private-fixture probes/faults require exact method/origin/path/query/status/request correlation. Retain all errors; never exempt all 404s or all console errors. Prefer an owned valid Git/favicon workspace rather than inducing unrelated missing-resource probes.
